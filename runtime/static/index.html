Runtime error check

Finds code that will crash when it runs (syntax errors, undefined names, broken imports, wrong arguments) by reading the source. The repository's code is never executed.

Coverage notes

    Checks Python (syntax, NameError, UnboundLocalError, in-repo ImportError, wrong call arguments, broken format strings) and JavaScript syntax. Third-party packages and errors that depend on data or configuration are only visible when the code actually runs.
